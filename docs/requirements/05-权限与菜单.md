## 2. 权限串

- **FR-05-04** 新 REST 端点前缀沿用 `/quality_control/plan`，权限串对齐现有 `quality_control:*` 风格：

| 权限串 | 动作 |
|---|---|
| quality_control:plan:list | 列表查询 |
| quality_control:plan:query | 详情 / 下次触发时间 / 调度摘要 |
| quality_control:plan:add | 新增 |
| quality_control:plan:edit | 编辑 + 启用 / 暂停（生命周期开关归入 edit） |
| quality_control:plan:remove | 删除 |
| quality_control:plan:run | 立即执行 |

- **FR-05-05** 终止权限沿用现有 records:stop；执行记录页新增展示批次 / 触发源 / 触发者 / 失败原因列不需新权限串（归入现有 records:list/query）。
- **FR-05-06** SDK 调用（进程内）不走 ruoyi 鉴权链——集成间信任边界与 composer 被调方式一致；但留痕字段（sourceName）必须非空（03 §FR-03-09）。
