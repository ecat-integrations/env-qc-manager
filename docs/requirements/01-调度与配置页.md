# 01 · 调度与配置页

> 决策依据：D1（自建精确唤醒）、D3（开始=启用调度）、D4/D6/D7（类型与时长）、D9（校准仪展示）。

## 1. 调度引擎

- **FR-01-01** qcm 模块内自建调度器：单线程调度线程 + `ScheduledExecutorService`，生命周期挂集成入口（onStart 启动、onPause/onRelease 关停、幂等 start），参考 adm `AsmStatRefreshScheduler.java:23-40` 模式。不依赖 ruoyi-quartz / sys_job / cron。
- **FR-01-02** 精确唤醒：调度器维护全部 ACTIVE 计划的 `next_fire_time`，取最早者 `schedule(唤醒, 精确 delay)`；触发后重算该计划下次时刻并重挂；计划集为空时不产生任何周期唤醒（非每秒 beat）。
- **FR-01-03** 下次触发时刻计算为纯函数 `computeNextFireTime(scheduleConfig, after)`：无 IO、无时钟读取（时刻由入参给定），可用虚拟时钟确定性单测。
- **FR-01-04** `next_fire_time` / `last_fire_time` 持久化到 `qcm_plan`；core 重启后调度器从表载入 ACTIVE 计划恢复调度。
- **FR-01-05** misfire（停机错过）：启动载入时发现 `next_fire_time` 已过 → 不补跑（D1），从当前时刻重算下次并写回，日志留痕，**不写执行记录**（⚠️ OPEN-01，与「到点但忙写失败记录」严格区分，见 02 §3）。
- **FR-01-06** 时区：Asia/Shanghai wall clock（core TZ），中国无夏令时，无跨时区换算。
- **FR-01-07** 精度：唤醒误差目标 < 1s（`ScheduledExecutorService` 毫秒级能力）；可选增加 30s 低频巡检兜底时钟漂移 / 漏重挂（防御性，不承担触发职责）。
- **FR-01-08** 配置变更联动：新增 / 编辑 / 启用 / 暂停 / 恢复 / 删除计划时，调度器即时重算受影响计划并重挂唤醒；不影响其他计划的已挂唤醒。

## 2. 调度方式语义

- **FR-01-09** 四种调度方式（schedule_type 单选）：
  - `DAILY` 每天：选 时:分；
  - `WEEKLY` 每周：选 星期（周一~周日，**多选**）+ 时:分；
  - `MONTHLY` 每月：选 日期（1~31，**多选**）+ 时:分；
  - `ONCE` 一次性：模式二选一——「立刻」（创建即触发一次）或「指定时刻」（到点触发一次）。
- **FR-01-10** 多选语义：每个所选星期 / 日期都会触发；同一计划同一天至多触发一次；多个选中值落在同一天时（如每月 1 与 15 选不同天，无冲突；不构造同值重复）以去重后的集合计算。
- **FR-01-11** 缺日边界：MONTHLY 所选日期在当月不存在（如 2 月无 30/31 日）→ 该月该日跳过：不触发、不报错、不补偿（与 cron 语义一致）。
- **FR-01-12** 时刻粒度：时:分（分默认 00），秒恒为 00（⚠️ OPEN-07）。
- **FR-01-13** ONCE 校验：「指定时刻」早于当前时刻 → 创建 / 编辑时校验拒绝（明确报错，不静默改为立刻）。
- **FR-01-14** ONCE 执行一次后进入 FINISHED（D11），触发即算（无论成功 / 失败 / 终止 / 冲突拒绝），不再触发。
- **FR-01-42** 计划有效期（沿用原表 plan_start_time/plan_end_time 设计，D18）：两字段可选；调度与 next_fire_time 计算受窗约束——触发时刻 t 须满足 `plan_start_time ≤ t ≤ plan_end_time`（NULL 边界=无界）。窗口结束后的到点不触发、日志留痕（misfire 同语义），状态保持不变（展示层提示「已过期」）。UI 步骤①提供「有效期起/止」可选日期时间（默认空=长期）。
- **FR-01-43** 有效期编辑语义：收窄/延长窗口后按新窗口重算 next_fire_time（与 FR-01-16 恢复同语义：从当前时刻起算，不追补）。
- **FR-01-44（D19 浓度展示规范）**：无浓度输入的类型按只读展示——零点类显示固定 0（禁用态输入框+「零点检查固定为零气」说明）；多点/准确度在第三步显示**每阶段绝对浓度表**（量程占比→浓度，值与单位由后端 estimate 统一返回：CO=ppm、其余=ppb，前端零换算逻辑）；跨度/人工核查的输入单位随仪器动态（CO 显示 ppm，提交自动换算 ppb，提示换算关系）。
- **FR-01-45（D19 时长步重置）**：第五步提供「恢复默认值」按钮——时长参数回到 composer 默认常量、清空覆盖差量、预估随之刷新。
- **FR-01-46（D19 流量全类型）**：标气/零气流量对所有类型可设（含零点类），缺省 4.0 L/min，范围 (0,50]；Validator 不再按类型拒绝。

## 3. 计划生命周期

- **FR-01-15** 计划状态机：`ACTIVE`（调度中）/ `PAUSED`（暂停）/ `FINISHED`（已完成，仅 ONCE）。转移：
  - 创建成功 → ACTIVE（默认启用；「立刻」模式创建即触发一次）；
  - ACTIVE ↔ PAUSED（启用 / 暂停 / 恢复）；
  - ONCE 触发后 ACTIVE → FINISHED；
  - 任意非执行中状态 → 删除（物理删除）。
- **FR-01-16** 启用 = 从当前时刻起计算 next_fire_time 并纳入调度；恢复同理（**不追补**暂停期间错过的触发点）。
- **FR-01-17** 暂停 = 到点不触发：移出调度集，next_fire_time 置空或保留（实现择一，语义以「不触发」为准），配置不变。
- **FR-01-18** 删除：物理删除计划行；若该计划关联批次正在执行，**不终止**，跑完归档（⚠️ OPEN-06）；执行记录不级联删除（记录冗余计划快照 record_snapshot，见 04 §3）。
- **FR-01-19** 编辑：ACTIVE / PAUSED 可编辑（含调度方式、类型、仪器、参数），保存后按新配置从当前时刻重算 next_fire_time；ONCE 已触发（FINISHED）或其批次执行中不可编辑。

## 4. 页面 · 列表

- **FR-01-20** 新页面「质控任务计划」挂 qcm vue-modules（路由与菜单见 05），列表列：计划名称 / 质控类型 / 仪器 / 调度摘要（人性化文案）/ 状态 / 下次触发时间 / 上次触发时间 / 创建人 / 操作。
- **FR-01-21** 人性化调度文案（调度摘要列，禁止出现 cron）：
  - `每天 02:00`；
  - `每周 周一、周三 02:00`（按周一~周日顺序排列）；
  - `每月 1、15 日 02:00`（数字升序）；
  - `一次性 · 立刻执行` / `一次性 · 2026-08-21 03:00`。
- **FR-01-22** 状态徽章：启用（绿）/ 暂停（灰）/ 已完成（蓝）。
- **FR-01-23** 操作按状态显隐：ACTIVE → 暂停 / 立即执行 / 编辑 / 删除；PAUSED → 启用 / 编辑 / 删除；FINISHED → 删除。操作均需二次确认（删除强制确认）。
- **FR-01-24** 立即执行：弹确认框展示将执行的参数摘要（类型 / 仪器 / 浓度 / 流量 / 时长总预估）→ 确认后走 MANUAL 触发链路（记录 ruoyi 登录用户，见 02 §1）；执行器忙时页面提示被拒原因（见 02 §3）。
- **FR-01-25** 列表支持按状态 / 质控类型筛选，按创建时间倒序。

## 5. 页面 · 创建 / 编辑（分步表单）

- **FR-01-26** 五步向导，步间可回退且已填内容不丢失：
  1. **调度方式**：单选 每天 / 每周 / 每月 / 一次性 + 对应时刻控件（周几多选 checkbox 组、几号多选网格 1~31；一次性选「立刻」或日期时间选择器）。
  2. **任务类型与仪器**：类型下拉 8 种（见 FR-01-27）；仪器选择规则见 FR-01-28。计划名称本步填写（必填）。
  3. **浓度**：仅需要浓度的类型显示（见 FR-01-29），单位 ppb。
  4. **标气流量**：全部类型显示（D19，含零点类），默认 4.0 L/min，范围 (0,50]；页面同时**只读展示**当前自动取用的校准仪（D9，展示为「执行时自动选择」）。
  5. **阶段时长参数**：见 §6。
- **FR-01-27** 任务类型清单（下拉 8 项，D6）：

  | 类型 | 说明 | 仪器选择 | 浓度 | 流量 |
  |---|---|---|---|---|
| 零点检查（现有 zero_check） | 单仪器 | 单选 1 台 | 固定 0（只读展示） | 可选，默认 4.0（D19） |
  | 多仪器零点质控（新） | N 台同时零点检查（D4） | **多选 1~4 台** | 固定 0（只读展示） | 可选，默认 4.0（D19） |
  | 跨度核查（span_check） | 单仪器 | 单选 | 必填 ppb | 可选（默认 4.0） |
  | 线性核查（multi_check） | 单仪器 | 单选 | 按量程百分比序列（FR-01-29） | 可选 |
  | 精密度核查（precision_check） | 单仪器 | 单选 | 不需要 | 可选，默认 4.0 |
  | 准确度核查（accuracy_check） | 单仪器 | 单选 | 按量程百分比序列 | 可选 |
  | 转换效率检查（conversion_check） | 仅 NOx 转换炉 | **锁定 NOx 不可改** | 不需要 | 可选，默认 4.0 |

- **FR-01-28** 仪器候选恒为 SO2 / NOx / CO / O3（展示名 NOx，代码键沿用现有 parameter 惯例 NO2↔NOx 映射，`LogicDeviceBindingIds.java:63`）。
- **FR-01-29** 浓度表达：跨度 / 人工核查填绝对浓度 ppb；线性 / 准确度展示并允许编辑量程百分比序列（见 §6 参数表）；零点浓度恒 0、转换效率无浓度。
- **FR-01-30** 表单校验规则（失败逐条明示，不静默修正；流量规则 D19 修订为全类型统一 (0,50]）：
  - 计划名称非空；调度时刻合法（时 0-23 / 分 0-59）；周几 / 几号至少选一；
  - ONCE 指定时刻必须晚于当前时刻（FR-01-13）；
  - 多仪器零点至少选 1 台仪器；其余类型必选 1 台；
  - 浓度 > 0（需要浓度的类型）；流量 ∈ (0, 50]；
  - 百分比序列：存储为 0~1 小数（如 0.1），升序，至少 2 项；界面以百分比呈现（10%）；
  - 时长参数：各项 > 0 且不小于 1 秒（整数秒）。

## 6. 阶段时长参数（D7）

- **FR-01-31** 编辑对象是 composer 的底层参数（非阶段秒数）：按所选类型显示相关参数，**预填 composer 默认值**，可改；未改的项不落库（`duration_overrides` 稀疏存储）。
- **FR-01-32** 各阶段预估时长**只读展示**：按当前编辑中的参数值实时计算各阶段（阶段名 + 秒数）+ 总预估 + 恢复阶段固定 120 秒提示（`AbstractCalibrationFlow.java:92,106`）。计算公式与 composer 执行同源（qcm 调 composer 的预估能力，保证「预估=实际计划」；实现方式实施定，禁止在 qcm 复制公式造成双源漂移）。
